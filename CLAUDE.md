# Плагин «Аниме» для Lampa

Весь плагин — один файл `shikimori.js`. Пользователи ставят его по ссылке GitHub Pages,
которая отдаёт ветку `main`: слияние в `main` — это и есть выпуск. В каждом выпуске
поднимайте `VERSION` в начале файла и описывайте изменения в `README.md`.

## Где он работает

Lampa на телевизорах: старый WebKit (Tizen, webOS), медленный localStorage, пульт вместо мыши.

- Только ES5: `var`, `function`, без стрелок, `let/const`, шаблонных строк, `Array.prototype.find/includes`,
  `Object.assign`, `Promise`. Проверка — `npm run es5` и `npm run lint` в `tests/`.
- Хранилище — `Lampa.Storage` целиком в JSON: не пишите его в цикле на каждый ответ.
- Сеть — только через `NetPool` с таймаутами. Экран не должен ждать один зависший запрос.
- Фокус пульта: убирая карточку, сначала переводите фокус (`dropCard`), потом удаляйте элемент.
- Слушатели на `document` и таймеры вешайте один раз, а не при каждом показе экрана.

## Источники данных и их ловушки

- **Shikimori GraphQL** (`shikimori.io`): у сервера лимит сложности 190 и глубины 5 — проверка `npm run complexity`.
  Один тайтл = один сезон или часть («Spy x Family» и «Spy x Family Part 2» — разные записи).
- **ARM** (`arm.haglund.dev`): соответствие MAL → TMDB. Номер сезона TMDB он берёт из
  `Fribb/anime-lists` (`raw.githubusercontent.com/Fribb/anime-lists/master/anime-list-full.json`),
  а там у десятков сериалов все сезоны записаны первым со сквозной нумерацией, хотя в TMDB они
  раздельные («Монолог фармацевта», «Фрирен», «Звёздное дитя»). Номеру сезона из ARM не верьте слепо.
- **TMDB** — через `Tmdb.get`: прокси Lampa, запасной путь через CUB. Номера фильмов и сериалов
  пересекаются — ключи кешей различайте по виду (`TmdbInfo.key`).
- **Kodik** (`kodik-api.com`): сколько серий озвучено; нумерация — по записи Shikimori.

## Отметки просмотра

Lampa хранит отметку серии под `hash(сезон, серия, original_name карточки TMDB)` в нумерации
сезонов TMDB. Ставится она нажатием на серию в карточке Lampa или досмотром. Плагин читает
отметки через `Lampa.Timeline.watchedEpisode` (`Progress.lastWatched`), а свои отметки
«просмотрено» хранит отдельно (`Seen`).

Сезон Shikimori → сезон TMDB: `Seasons` (сезоны TMDB по датам премьер), затем `pickPlace`
выбирает гипотезу (TMDB, база, хронология), затем `Progress.judge` решает, сколько серий
просмотрено. Строку «Новые серии» отбирает `isFresh`.

## Как вносить изменения

1. Ошибку сначала воспроизведите сценарием в `tests/run.js`. Он должен падать на текущем
   `main` и проходить после исправления. Как это сделать — в `tests/README.md`.
2. `cd tests && npm install && npm run check`: ES5, eslint, все сценарии эмулятора.
3. Изменения в отрисовке, фокусе или полной карточке проверяйте в настоящей Lampa:
   `npm run setup` (один раз), потом `npm run e2e`.
4. Комментарии в коде — по-русски и о том, *почему* так: что ломалось и на каком тайтле.
   Сверяйтесь со стилем соседнего кода.
5. Изменения, затрагивающие прогресс, сезоны, кеши или сеть, отдайте агентам из `.claude/agents`
   (`season-logic-reviewer`, `lampa-runtime-reviewer`, `adversarial-tester`). Их находки
   перепроверяйте сценарием, прежде чем исправлять.
6. Ветка → PR в `main`; сливает владелец репозитория.

## Окружение облачных сессий

Настоящие API (Shikimori, ARM, TMDB/CUB, Kodik) из облачного окружения недоступны —
поэтому проверки работают на фейковых серверах. GitHub (включая `raw.githubusercontent.com`)
доступен: данные ARM можно сверять по спискам Fribb.
