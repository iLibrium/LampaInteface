# Аниме Shikimori — плагин для Lampa

Плагин добавляет в [Lampa](https://github.com/yumata/lampa) полноценный аниме-раздел на данных
[Shikimori](https://shikimori.one): каталог с фильтрами, ваши списки просмотра, календарь выхода
серий и переход на карточки TMDB, которые Lampa уже умеет искать по торрентам и онлайн-балансерам.

## Установка

Настройки → Расширения (Плагины) → Добавить плагин, вставить URL:

```
https://ilibrium.github.io/LampaInteface/shikimori.js
```

Если GitHub Pages для репозитория не включён, используйте CDN-ссылку на файл:

```
https://cdn.jsdelivr.net/gh/iLibrium/LampaInteface@main/shikimori.js
```

После установки в левом меню появится пункт **Аниме**.

## Возможности

### Главный экран

| Строка | Что показывает |
|---|---|
| Меню | Быстрые кнопки: Поиск, Каталог, Календарь, Указать ник Shikimori |
| Я смотрю | Список `watching`/`rewatching` вашего профиля Shikimori |
| Скоро новые серии | Серии, выходящие в ближайшие 30 дней, по вашим спискам и закладкам Lampa/CUB |
| Сейчас смотрят в Lampa | Аниме-каталог CUB (`sort=now_playing&cat=anime`), фолбэк — TMDB discover по ключевому слову anime |
| Популярные онгоинги / Лучшее сезона / Ожидаемые анонсы | Ленты Shikimori |

**Подсветка новых серий.** На карточке в «Я смотрю» зелёным выводится `+N` — сколько серий вышло
сверх того, что отмечено в вашем списке Shikimori. Такие тайтлы поднимаются в начало строки.
В «Скоро новые серии» синей плашкой показывается дата и номер ближайшей серии
(«завтра 15:30 · 7 серия»).

### Каталог и фильтры

Экран каталога открывается кнопкой «Каталог». Сверху — строка фильтров-чипсов, каждый открывает
TV-совместимый список выбора:

- **Поиск** — текстовый поиск по названию (экранная клавиатура Lampa)
- **Жанр** — мультивыбор из жанров Shikimori (отмеченные помечены галочкой)
- **Тип** — TV, фильм, OVA, ONA, спешл, TV-спешл
- **Статус** — онгоинг, анонс, вышло
- **Сезон** — текущий и прошлые сезоны, годы, 1990-е, 1980-е
- **Оценка** — от 9 / 8 / 7 / 6
- **Сортировка** — по популярности, рейтингу, дате выхода, названию, случайно
- **Сброс** — очистить все фильтры

Активный фильтр подсвечивается и показывает выбранное значение прямо в чипсе («Статус: Онгоинг»).
Пагинация — бесконечная прокрутка по 36 карточек.

### Матчинг с TMDB и CUB

При клике по карточке плагин находит соответствующую запись TMDB и открывает штатную карточку Lampa
(со всеми источниками, торрентами и закладками — то есть работает и CUB-синхронизация):

1. Кэш соответствий в `Lampa.Storage` (30 дней; отрицательные результаты — 3 дня)
2. [ARM](https://arm.haglund.dev) — маппер MyAnimeList → TMDB (id Shikimori = id MAL); для списков
   и календаря запрашивается батчем
3. Если у ARM нет TMDB, но есть IMDB/TVDB — TMDB `find/{id}?external_source=…`
4. Фолбэк — поиск TMDB по названию (english → romaji → русское) с очисткой «Season N»/«Part N»,
   оценкой по схожести названия, году, жанру «Анимация» и японскому происхождению. При нескольких
   близких кандидатах показывается список выбора

### Карточка фильма

Для аниме-карточек (жанр 16 + японское происхождение) плагин добавляет:

- рейтинг Shikimori рядом со штатными рейтингами
- строку «Следующая серия: N серия · дата» для онгоингов

### Списки Shikimori

Укажите ник в настройках плагина (или кнопкой «Указать ник Shikimori» на главном экране).
OAuth не нужен — читаются публичные списки профиля, поэтому в приватности Shikimori список должен
быть открыт. Данные берутся из `GET /api/v2/user_rates` + GraphQL `animes(ids:)`, кэш 10 минут.

## Настройки

Настройки → Аниме Shikimori:

| Параметр | Описание |
|---|---|
| Ник на Shikimori | Профиль, из которого читаются списки |
| Показывать 18+ | Отключает фильтр цензуры Shikimori |
| CORS-прокси | Префикс перед адресом Shikimori, если прямой доступ заблокирован (например `https://my-proxy.example/`) |
| Очистить кэш | Сброс кэша соответствий TMDB, календаря, жанров и списков |

## Как это устроено

Один ES5-файл без сборки, как и все плагины Lampa. Основные части:

- `NetPool` — отменяемый XHR-слой (каждый компонент чистит свои запросы в `destroy`)
- `Shiki` — API Shikimori: GraphQL для каталога/карточек, REST для календаря, жанров и списков
- `Match` — цепочка сопоставления MAL → TMDB с кэшем
- `UserData` — списки пользователя, закладки Lampa и календарь на 30 дней
- `ShikiCard` / `ActionCard` — карточки с бейджами (тип, оценка, статус, `+N`, дата серии)
- `MainComponent` (на `Lampa.InteractionMain`) и `CatalogComponent` (собственная сетка + шапка фильтров)

### Источники данных

| Данные | Endpoint |
|---|---|
| Каталог, поиск, карточки | `POST https://shikimori.io/api/graphql` |
| Списки пользователя | `GET https://shikimori.io/api/v2/user_rates?user_id=&target_type=Anime` |
| Календарь серий | `GET https://shikimori.io/api/calendar` |
| Жанры | `GET https://shikimori.io/api/genres` |
| Детали для карточки | `GET https://shikimori.io/api/animes/{mal_id}` |
| MAL → TMDB | `GET/POST https://arm.haglund.dev/api/v2/ids` |
| Популярное в Lampa | `https://tmdb.{cub_domain}/?sort=now_playing&cat=anime` |

Обращения идут на `shikimori.io` (домен `shikimori.one` редиректит без CORS-заголовков, из браузера
не работает). У Shikimori лимит 5 запросов/сек, поэтому календарь кэшируется на час, жанры — на
сутки, списки — на 10 минут.

## Ограничения

- Записи в списки Shikimori нет (нужен OAuth) — плагин работает только на чтение
- Списки профиля должны быть публичными
- «Сейчас смотрят в Lampa» использует агрегированный каталог CUB: отдельного API счётчика
  просмотров за 30 дней у Lampa/CUB не существует
- Один тайтл TMDB может соответствовать нескольким записям Shikimori (сезоны), карточка открывается
  на уровне сериала
