# Аниме — раздел для Lampa

Плагин добавляет в [Lampa](https://github.com/yumata/lampa) полноценный аниме-раздел: каталог с
фильтрами, ваши списки просмотра, календарь выхода серий и переход на карточки TMDB, которые Lampa
уже умеет искать по торрентам и онлайн-балансерам. Данные берутся у [Shikimori](https://shikimori.one)
(каталог, списки, календарь) и Kodik (доступность озвучки), но в интерфейсе источник назван только
там, где это действительно нужно: ник профиля, адрес API, прокси. Пункт меню называется «Аниме».

## Установка

Настройки → Расширения (Плагины) → Добавить плагин, вставить URL:

```
https://ilibrium.github.io/LampaInteface/shikimori.js
```

Если GitHub Pages для репозитория не включён, используйте CDN-ссылку на файл:

```
https://cdn.jsdelivr.net/gh/iLibrium/LampaInteface@main/shikimori.js
```

После установки в левом меню появится пункт **Аниме**.

## Возможности

### Главный экран

| Строка | Что показывает |
|---|---|
| Кнопки | Поиск, Каталог, Календарь, Указать ник Shikimori |
| Новые серии | То, что **уже можно посмотреть с озвучкой** и вы ещё не видели |
| Я смотрю | Закладки «Смотрю», следом — вычисленное по факту просмотра |
| Есть продолжение | Сиквелы того, что вы досмотрели |
| Свежая озвучка | Всё, что озвучили за последние полтора дня, независимо от ваших закладок |
| Сейчас смотрят в Lampa | Аниме-каталог CUB (`sort=now_playing&cat=anime`), фолбэк — TMDB discover |
| Популярные онгоинги / Лучшее сезона / Ожидаемые анонсы | Ленты Shikimori |
| Позже | Закладки категории «Позже» |

Даты эфира в Японии на главной нет намеренно: расписания выхода озвучки не существует, а японская
дата не отвечает на вопрос «что можно включить». Календарь остался отдельным экраном за кнопкой.

**Как считается «Новые серии».** Источник — [Kodik](#новые-серии-kodik). Сколько серий вы не
посмотрели, плагин знает из вашего списка Shikimori (точно) или из отметок просмотра Lampa. Тогда
на карточке зелёным `+N`. Если прогресса нет ниоткуда, а озвучка обновлялась на днях — тайтл всё
равно показывается, но без счётчика: честнее показать «18 серия · AniLiberty», чем выдумать число.

**Как считается «Я смотрю».** Сверху — закладки категории «Смотрю» как есть. Следом — вычисленное:
всё, где есть ваш прогресс и остались непросмотренные серии, из любой категории избранного и из
списка Shikimori. Тег в Lampa ставится руками и не снимается, поэтому досмотренное висит в нём
месяцами; вычисленная часть от этого свободна — тайтл уходит из неё сам.

**Убрать лишнее.** Долгое нажатие на карточке → «Не интересует»: тайтл исчезает из всех личных
строк. Вернуть — в настройках, «Скрытые тайтлы». Там же в меню — «Отметить просмотренным до серии N»
для того, что досматривали не в Lampa, «Выбрать другую карточку TMDB», если сопоставление ошиблось,
и «Искать в Lampa» — штатный поиск с названием тайтла.

«Отметить все серии просмотренными» запоминается самим плагином: сколько серий было доступно в момент
отметки. Отметки Lampa тоже ставятся — по настоящему оригинальному названию TMDB и в том сезоне, где
вышла озвучка, — но угадать их можно не всегда (у тайтла из списка Shikimori нет названия TMDB вовсе),
и раньше отмеченное возвращалось после перезапуска. Карточка при этом убирается из строки, а фокус
переходит на соседнюю — раньше он оставался на спрятанной, и пульт внутри экрана переставал работать.

В строке «Новые серии» метка на карточке — это вышедшая серия и студия («7 серия · AniLibria.TV»),
а не прогресс: так видно, в чьей озвучке серия засчитана. Прогресс виден по полосе снизу постера.

На пункте меню «Аниме» показывается число тайтлов с новыми сериями.

### Каталог и фильтры

Экран каталога открывается кнопкой «Каталог». Сверху — штатная панель `Lampa.Filter`
(«Поиск / Сортировка / Фильтр»), как в родном каталоге приложения:

- **Поиск** — текстовый поиск по названию (экранная клавиатура Lampa)
- **Жанр** — мультивыбор из жанров Shikimori (отмеченные помечены галочкой)
- **Тип** — TV, фильм, OVA, ONA, спешл, TV-спешл
- **Статус** — онгоинг, анонс, вышло
- **Сезон** — текущий и прошлые сезоны, годы, 1990-е, 1980-е
- **Оценка** — от 9 / 8 / 7 / 6
- **Сортировка** — по популярности, рейтингу, дате выхода, названию, случайно
- **Сброс** — очистить все фильтры

Выбранное значение видно прямо в панели («Статус: Онгоинг»).
Пагинация — бесконечная прокрутка по 36 карточек.

### Новые серии (Kodik)

Источник строки «Новые серии» — [Kodik](https://kodik-api.com): он ищет по `shikimori_id` и отдаёт
`last_episode` **по каждой студии озвучки**, то есть отвечает на вопрос «серию уже можно
посмотреть по-русски», а не «серия вышла в Японии».

Как это устроено:

1. Лента `/list?sort=updated_at` читается **с места прошлой сверки**: плагин помнит, до какой строки
   дочитал, и раз в 15 минут листает ленту, пока не дойдёт до уже виденного (не глубже 10 страниц
   по 100 строк). Раньше каждый раз брались две свежие страницы, и серия, вышедшая днём, к вечеру
   из них выпадала — новой она больше нигде не считалась.
2. Статус тайтла в ленте не ограничивается онгоингами: последние серии сезона озвучивают уже после
   того, как эфир в Японии закончился, и с таким фильтром они не приходили никогда. Чтобы
   перезаливка давно озвученного не выглядела новинкой, у вышедших тайтлов свежей считается только
   озвучка, начатая или законченная в последние полгода.
3. Всё, за чем вы следите (списки Shikimori и закладки Lampa), перепроверяется точечно через
   `/search?shikimori_id=`: неизвестное — сразу, выходящее — раз в 6 часов, вышедшее, но ещё не
   озвученное целиком, — раз в сутки. До 24 запросов за обновление, по 3 одновременно.
4. У закладок ищутся новые сезоны: база соответствий узнаёт о них через недели, поэтому плагин
   идёт от известных сезонов по связи «продолжение» у Shikimori.
5. Сколько серий вы не видели: для списков Shikimori — точное число из вашего списка (по тому же
   сезону, что и озвучка); для закладок — по отметкам Lampa. Досмотрели прошлый сезон, а озвучку
   получает следующий — все его серии считаются новыми.
6. Номер серии от Kodik сверяется со счётчиком эфира (Kodik и Shikimori, берётся больший): на одну
   серию вперёд верим озвучке — счётчик эфира обновляется с опозданием, — а заметно больше
   означает другую нумерацию, и тогда верим эфиру.
7. Серия считается новой 14 дней. Дальше это уже не новинка, а недосмотренный бэклог — он виден
   в «Я смотрю».
8. Счётчик на пункте меню пересчитывается раз в полчаса, пока приложение открыто.
9. Главная не ждёт все точечные запросы: через 2 секунды она показывает то, что уже пришло,
   остальное дорабатывает в фоне и попадает в следующий показ. Лента Kodik грузится параллельно с
   сопоставлением закладок, связи сезонов держатся в памяти полчаса, и дольше 10 секунд главная не
   ждёт ни один источник. Соответствия TMDB для карточек на экране подтягиваются заранее одним
   запросом, поэтому карточка по нажатию открывается сразу.

Ограничения, о которых честно стоит знать:

- Kodik — неофициальный агрегатор. Домен уже переезжал (`kodikapi.com` отключён регистратором
  в марте 2026), поэтому адрес вынесен в настройки.
- Kodik получает серии от студий не мгновенно: на сайте самой студии серия может появиться раньше.
  Плагин узнаёт о серии не позже чем через 15 минут после того, как она появилась в Kodik, пока
  приложение открыто, а если оно было закрыто — при следующем запуске.
- Токены — общий публичный пул, они периодически умирают. Встроено три; если перестанут работать,
  впишите свой в настройках. Плагин сам перебирает токены при любой ошибке.
- Если Kodik недоступен, строка просто не появляется — остальной плагин работает как обычно.
- Строку можно выключить: настройки → «Строка "Новые серии"».

### Матчинг с TMDB и CUB

При клике по карточке плагин находит соответствующую запись TMDB и открывает штатную карточку Lampa
(со всеми источниками, торрентами и закладками — то есть работает и CUB-синхронизация). Саму
карточку плагин не запрашивает: её загружает Lampa тем же путём, что и любую свою, — через
источник из настроек (TMDB или CUB), прокси TMDB и зеркала CUB. Раньше плагин сперва сам тянул
карточку с TMDB напрямую и при недоступном TMDB показывал «Не найдено» там, где Lampa открыла бы
её без труда.

1. Кэш соответствий в `Lampa.Storage`: найденное по базе — 30 дней, найденное поиском — неделя,
   «не найдено» — сутки, выбранное вручную — навсегда
2. [ARM](https://arm.haglund.dev) — маппер MyAnimeList → TMDB (id Shikimori = id MAL); для списков
   и календаря запрашивается батчем. Тип записи у ARM — тип MAL, а не TMDB: у OVA, ONA и спешлов
   номер TMDB бывает и сериалом, и фильмом, и открывался не тот. Теперь в неоднозначных случаях
   вид уточняется у TMDB — какая из двух карточек похожа на наше аниме
3. Если у ARM нет TMDB, но есть IMDB/TVDB — TMDB `find/{id}?external_source=…`
4. Поиск TMDB по всем названиям — японскому, русскому, английскому, ромадзи, — каждое на своём
   языке и **без фильтра по году**: у второго сезона год свой, а сериал в TMDB начался раньше, и с
   фильтром TMDB не находил его вовсе. Пометки сезона («2nd Season», «第2期», «2 сезон», «Part 2»)
   срезаются, названия сравниваются по парам символов — это работает и для японского, где нет
   пробелов
5. Нет уверенного совпадения — берётся карточка предыдущего сезона: новый сезон почти всегда живёт
   в том же сериале TMDB, а в базе соответствий появляется через недели
6. Несколько похожих — список выбора; выбранное запоминается. Не нашлось ничего — открывается
   поиск Lampa с названием тайтла
7. Сопоставление ошиблось — долгое нажатие → «Выбрать другую карточку TMDB»

Запросы плагина к TMDB идут по адресу, который строит Lampa (с её прокси); если он не ответил,
плагин пробует сквозной TMDB у CUB и дальше пользуется тем путём, что сработал. Раньше рабочий путь
помнился только до перезапуска: там, где TMDB заблокирован, каждый запуск Lampa первый запрос ждал
8 секунд впустую, и главная собиралась без названий и сезонов TMDB — а от них зависит, какие серии
новые. Теперь сработавший путь помнится сутки — в обе стороны: и CUB, выручивший при недоступном
TMDB, и TMDB, когда зависло зеркало CUB. Без такой памяти у кого источник в Lampa — CUB, плагин
сразу идёт туда. Если TMDB не отвечал, а CUB ответил, через CUB открываются и карточки — иначе
Lampa грузила бы их тем же недоступным TMDB. Ответ «такого номера нет» плагин засчитывает только
от самого TMDB: 404 от зеркала CUB раньше запоминался навсегда, и закладка теряла прогресс.

Обратное сопоставление (закладка TMDB → тайтлы Shikimori) различает фильмы и сериалы: номера у них
в TMDB пересекаются, и сериалу доставались записи фильма с тем же номером. Чего нет в ARM, плагин
ищет в Shikimori по оригинальному названию закладки.

### Интерфейс

Экран рассчитан на просмотр с трёх метров и на пульт, а не на мышь:

- **Фокус видно.** Карточка в фокусе получает белую рамку и слегка увеличивается. Штатная обводка
  Lampa рисуется снаружи постера и срезается нашим `overflow:hidden` (им обрезается полоса
  прогресса), поэтому рамка нарисована внутрь бокса. Появляется она мгновенно, без перехода по
  цвету: плавный `border-color` на скруглённой рамке перерисовывается каждый кадр, и замер в
  Chromium показал, что именно он съедал кадры — 216 перерисовок против 21 без него.
- **Движется сама карточка, а не постер.** У `.card` уже стоит `will-change: transform`, то есть
  Lampa подняла её в отдельный слой: масштаб такого слоя видеокарта делает без перерисовки.
  `.card__view` лежит внутри слоя, на нём скругление и обрезка, и его масштабирование заставляло
  перерисовывать маску вместе с постером. На настоящей вёрстке плагина разница — 238 перерисовок
  против 44 за семь переводов фокуса. Штатный «подскок» Lampa на наших карточках выключен: два
  движения друг поверх друга и читались как рывок.
- **Нажатие отзывается.** Карточка коротко проседает — у пульта нет тактильной отдачи, и без
  этого непонятно, засчиталось ли нажатие.
- **Постер проявляется, а не возникает.** Он грузится лениво и может приехать ровно в момент
  перевода фокуса; подмена картинки рывком тоже читается как дёрганая анимация.
- **Скелетоны вместо крутилки.** Пока едут данные, на экране стоит будущая раскладка: сетка плиток
  в каталоге и календаре, строки на главной.
- **Постеры грузятся по мере появления в кадре**, а не все разом: каталог из 36 карточек больше не
  запрашивает 36 картинок сразу.
- **Фон следует за фокусом** — кадр тайтла, на котором вы стоите, уходит в фон приложения.

Движение карточек можно выключить отдельно — «Движение карточек» в настройках раздела: отключать
ради него все анимации Lampa было бы слишком крупной мерой. Все движения выключаются и вместе с
анимациями самой Lampa (`Настройки → Интерфейс → Анимация`):
на слабых панелях это первое, что отключают, и плагин обязан это уважать. Тяжёлых для телевизора
эффектов — теней, размытий, фильтров — в анимациях нет, только `transform` и `opacity`.

### Карточка фильма

Для аниме-карточек (жанр 16 + японское происхождение) плагин добавляет:

- рейтинг Shikimori рядом со штатными рейтингами
- строку «Следующая серия: N серия · дата» для онгоингов

### Списки Shikimori

Ник в настройках достаточно указать, чтобы читать публичные списки — OAuth для этого не нужен,
но приватность профиля должна быть открытой. Данные берутся из `GET /api/v2/user_rates` +
GraphQL `animes(ids:)`, кэш 10 минут.

### Прогресс просмотра

Плагин только читает: сколько серий просмотрено, он берёт из отметок самой Lampa и из вашего
списка на Shikimori, беря большее из двух. Обратной записи нет и не планируется — она требовала
OAuth, а на телевизоре ввод Client ID и Client Secret с пульта себя не оправдывает.

Серии, отмеченные в самой Lampa (нажатие на серию в списке серий или досмотренная серия), Lampa
записывает по оригинальному названию карточки TMDB и номеру сезона TMDB. У закладок это название
есть, а у тайтлов из списка Shikimori и из лент его не было, и такие отметки плагин раньше не видел
вовсе — ни в одной версии. Теперь название TMDB запоминается, когда карточка открывается, и
дозапрашивается в фоне для списка «Смотрю» и карточек на экране.

Номер сезона TMDB сверяется с самим TMDB. База соответствий (ARM, она же `Fribb/anime-lists`)
знает его не всегда: у «Монолога фармацевта» все три сезона записаны в ней первым сезоном TMDB
со сквозной нумерацией (второй — серии 25–48), а в TMDB это три отдельных сезона. Отметка Lampa
«сезон 3, серия 1» не сходилась ни с чем, и просмотренный тайтл висел в «Новых сериях». Таких
тайтлов в базе десятки. Теперь сезон Shikimori — это сезон TMDB, начавшийся в день его премьеры;
такого нет — он продолжает нумерацию предыдущего сезона TMDB (вторая часть сплит-кура), и серии
прошлых частей вычитаются. Список сезонов TMDB запрашивается только у того, что выходит сейчас,
кешируется на неделю и бесплатно обновляется при открытии полной карточки. Если TMDB не ответил,
действует запасное правило: отметка в сезоне позже, чем считает база, относится к последнему
сезону тайтла, если номер серии в него помещается, а «серия 24» у сезона из 12 серий — это
прошлый сезон, и новый считается не начатым.

Сезонов TMDB плагин ещё не знает (TMDB не ответил) — считает по сумме: сколько серий отмечено во
всех сезонах TMDB вместе, минус серии частей, вышедших раньше. Тогда неважно, как TMDB нарезал
сезоны — раздельно, сквозной нумерацией или две части в одном сезоне (у «Клинка, рассекающего
демонов» «Бесконечный поезд» и «Квартал красных фонарей» — один сезон TMDB). Сумме плагин верит,
только когда она правдоподобна: прошлые части отмечены целиком, а отмечено не больше, чем вообще
вышло. Иначе (прошлые сезоны смотрели не в Lampa) — считает внутри сезона по базе соответствий.
Когда сезоны TMDB известны, сумма не нужна и даже вредна: серии, которые TMDB держит в прошлых
сезонах, а Shikimori не считает (рекап, «нулевая» серия), прибавлялись бы к текущей части.
Спецвыпуски в сумму не входят: рекапы между сезонами и всё, что база относит к сезону 0.
Исключение — то, чему база дала обычный сезон: «Фиц» у «Реинкарнации безработного» TMDB считает
первой серией второго сезона.

Тайтл на много сезонов TMDB — «Ван-Пис», «Детектив Конан», «Наруто: Ураганные хроники» — у
Shikimori одна запись на сотни серий, а TMDB режет его на сезоны по аркам. Раньше отметка в
сезоне позже первого значила «этот уже позади», и такой тайтл из «Новых серий» пропадал совсем.
Теперь номер серии считается сквозным по числу серий в сезонах TMDB: «сезон 4, серия 30» после
сезонов из 61, 16 и 14 серий — это 121-я серия.

Тайтлы из списка Shikimori считаются так же, как закладки, — по всем сезонам своей карточки TMDB.
Ответа базы о сезонах карточки главная ждёт не дольше двух секунд: не дождалась — берёт его из
кеша, а нет и там — считает по одному тайтлу, как раньше. Тем, у кого закладок нет, зависшая база
стоила бы иначе всех личных строк.

Новый сезон, которого база соответствий ещё не знает (она узнаёт о них через недели), плагин
находит через предыдущий сезон, а новый сериал — поиском по названиям в TMDB, как при открытии
карточки. Ищет в фоне, поэтому отметки Lampa у такого тайтла учитываются со следующего показа
главной. Не нашёл — повторит, когда база соответствий снова ответит «не знаю» (раз в сутки).

«Отметить просмотренным» ставит отметки серий в Lampa только там, где сезон TMDB известен
наверняка: он сверен с TMDB по премьере, следует из самих отметок или назван базой, когда TMDB
этот сезон ещё не завёл, а вышел он через год и больше после последнего сезона TMDB. Ближе — это
продолжение того же сезона: база нумерует по TVDB, и у «Клинка» «Квартал красных фонарей» у неё
третий сезон, а у TMDB — второй. Отметка в угаданном сезоне потом спорила бы с настоящей.

Отметку плагина «просмотрено» можно снять в меню карточки — «Снять отметку «просмотрено»». Она
откатывает и то, что «Отметить» сделало в самой Lampa: отметки серий, которых до неё не было
(досмотренные раньше остаются), и метку «Просмотрено» на закладке. «Очистить кэш» сбрасывает
отметки плагина вместе с кешем сезонов TMDB.

## Настройки

Настройки → Аниме:

| Параметр | Описание |
|---|---|
| Версия плагина | Что реально загружено. Плагин внедряется один раз при старте — если версия старая, перезапустите Lampa |
| Ник на Shikimori | Профиль, из которого читаются списки. Списки должны быть публичными |
| Вид карточек | Как в Lampa (по умолчанию), Компактный, Крупные постеры |
| Движение карточек | Карточка в фокусе слегка увеличивается, нажатие даёт отклик. Выключается отдельно от анимаций Lampa |
| Фон по карточке | Фон приложения меняется на кадр тайтла в фокусе. Работает, если фон включён в настройках Lampa |
| Показывать 18+ | Отключает фильтр цензуры Shikimori |
| Строка «Новые серии» | Главный переключатель данных Kodik |
| Засчитывать субтитры | Считать серию вышедшей, если есть только субтитры |
| Скрытые тайтлы | Убранные через «Не интересует». Галочка снимается — тайтл возвращается |
| Студии озвучки | Мультивыбор галочками: студий можно отметить сколько угодно. Список — весь словарь Kodik (`/translations/v2`), самые ходовые сверху, остальное ищется по названию. Лента Kodik запрашивается уже отфильтрованной по номерам выбранных студий. AniLibria и AniLiberty считаются одной студией. Не выбрано — засчитывается любая озвучка |
| Адрес Kodik API | По умолчанию `kodik-api.com`. Менять, если домен снова переедет |
| Токен Kodik | Свой токен, если встроенные перестали работать. Пусто — используются встроенные |
| CORS-прокси | Префикс перед адресом Shikimori, если прямой доступ заблокирован |
| Очистить кэш | Сброс сопоставлений TMDB, календаря, жанров, списков, известных серий и скрытых тайтлов. Карточки TMDB, выбранные вручную, остаются |

## Как это устроено

Один ES5-файл без сборки, как и все плагины Lampa. Основные части:

- `NetPool` — отменяемый XHR-слой (каждый компонент чистит свои запросы в `destroy`);
  429 и 5xx повторяются дважды с паузой — у Shikimori лимит 5 запросов в секунду
- `Shiki` — API Shikimori: GraphQL для каталога, карточек и связей, REST для календаря и списков;
  если REST-календарь не отвечает, ближайшие эфиры собираются из GraphQL по `nextEpisodeAt`
- `Kodik` — заменяемый адаптер доступности озвучки: настраиваемый хост, перебор токенов,
  лента `/list` со сверкой с места прошлого чтения, точечный `/search`, словарь студий
  `/translations/v2`, хранилище известных номеров серий, фильтр по студиям
- `Progress` — прогресс просмотра из отметок Lampa (`Timeline`, `online_watched_last`)
- `Titles` — приведение и сравнение названий (пометки сезона, японский, ромадзи)
- `Tmdb` — запросы плагина к TMDB: путь Lampa, запасной — сквозной TMDB у CUB
- `Match` — сопоставление MAL → TMDB и обратное TMDB → MAL, ручной выбор карточки
- `Hidden` — скрытые тайтлы. Один тайтл помнится сразу всеми своими номерами
  (Shikimori, MAL, TMDB): в каталоге он приходит одним, в закладках другим
- `UserData` — закладки Lampa, отслеживаемое, продолжения, свежая озвучка, календарь
- `ShikiCard` / `ActionCard` — карточки с бейджами по углам и полосой прогресса
- `MainComponent` (на `Lampa.InteractionMain`) и `CatalogComponent` (собственная сетка + шапка фильтров)

Ловушки Lampa, на которые здесь уже наступали: `wath` — это «Позже», а «Смотрю» — `look`;
`Line.append()` помечает отрисованный объект `ready` и во второй строке молча его пропускает;
закладка проходит через `Utils.clearCard`, и с полной карточки в ней остаётся `genres`, а не
`genre_ids`; сколько карточек рисовать в строке, решает сама Lampa — плагину этот рычаг не пробрасывается;
`Select.show` зовёт `onCheck` только у пунктов с `checkbox: true`, у остальных — `onSelect`;
внутри любого обработчика `Select` активен контроллер `select`, поэтому запоминать, куда вернуть
фокус, нужно ДО открытия списка, иначе пульт после выхода упирается в закрытое окно.

### Источники данных

| Данные | Endpoint |
|---|---|
| Каталог, поиск, карточки, связи сезонов | `POST https://shikimori.io/api/graphql` |
| Списки пользователя | `GET https://shikimori.io/api/v2/user_rates?user_id=&target_type=Anime` |
| Календарь серий | `GET https://shikimori.io/api/calendar` |
| Жанры | `GET https://shikimori.io/api/genres` |
| Детали для карточки | `GET https://shikimori.io/api/animes/{mal_id}` |
| MAL → TMDB | `GET/POST https://arm.haglund.dev/api/v2/ids` |
| TMDB → MAL | `GET https://arm.haglund.dev/api/v2/themoviedb?id=` |
| Поиск и проверка в TMDB | `Lampa.TMDB.api(...)`, запасной путь `https://tmdb.{cub_domain}/3/...` |
| Популярное в Lampa | `https://tmdb.{cub_domain}/?sort=now_playing&cat=anime` |
| Доступность озвучки | `GET https://kodik-api.com/list` и `/search?shikimori_id=` |
| Словарь студий озвучки | `GET https://kodik-api.com/translations/v2` |

Обращения идут на `shikimori.io` (домен `shikimori.one` редиректит без CORS-заголовков, из браузера
не работает). У Shikimori лимит 5 запросов/сек, поэтому календарь кэшируется на час, жанры — на
сутки, списки — на 10 минут.

Kodik запрашивается только простым GET без собственных заголовков: `OPTIONS`-преflight у него
отвечает 500, а ответы с ошибкой приходят без CORS-заголовков — в браузере это неотличимо от
сетевого сбоя, поэтому любая неудача трактуется как «токен мёртв» и берётся следующий.

## Ограничения

- Записи в списки Shikimori нет — плагин работает только на чтение
- Поиск у Shikimori выдаёт результаты по релевантности и параметр сортировки не применяет:
  в результатах поиска плагин упорядочивает страницу сам
- Списки профиля должны быть публичными
- «Сейчас смотрят в Lampa» использует агрегированный каталог CUB: отдельного API счётчика
  просмотров за 30 дней у Lampa/CUB не существует
- Один тайтл TMDB может соответствовать нескольким записям Shikimori (сезоны), карточка открывается
  на уровне сериала
- Отметки Lampa хранятся под оригинальным названием карточки TMDB. Если ни TMDB, ни его зеркало у
  CUB не отвечали ни разу, пока тайтл был в списке «Смотрю», названия плагин не знает, и отметки
  такого тайтла из списка Shikimori не видит до первого ответа. Тогда просмотренное считается по
  списку Shikimori
