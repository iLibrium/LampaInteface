# Аниме Shikimori — плагин для Lampa

Плагин добавляет в [Lampa](https://github.com/yumata/lampa) полноценный аниме-раздел на данных
[Shikimori](https://shikimori.one): каталог с фильтрами, ваши списки просмотра, календарь выхода
серий и переход на карточки TMDB, которые Lampa уже умеет искать по торрентам и онлайн-балансерам.

## Установка

Настройки → Расширения (Плагины) → Добавить плагин, вставить URL:

```
https://ilibrium.github.io/LampaInteface/shikimori.js
```

Если GitHub Pages для репозитория не включён, используйте CDN-ссылку на файл:

```
https://cdn.jsdelivr.net/gh/iLibrium/LampaInteface@main/shikimori.js
```

После установки в левом меню появится пункт **Аниме**.

## Возможности

### Главный экран

| Строка | Что показывает |
|---|---|
| Кнопки | Поиск, Каталог, Календарь, Указать ник Shikimori |
| Новые серии | То, что **уже можно посмотреть с озвучкой** и вы ещё не видели |
| Я смотрю | Закладки «Смотрю», следом — вычисленное по факту просмотра |
| Есть продолжение | Сиквелы того, что вы досмотрели |
| Свежая озвучка | Всё, что озвучили за сутки, независимо от ваших закладок |
| Сейчас смотрят в Lampa | Аниме-каталог CUB (`sort=now_playing&cat=anime`), фолбэк — TMDB discover |
| Популярные онгоинги / Лучшее сезона / Ожидаемые анонсы | Ленты Shikimori |
| Позже | Закладки категории «Позже» |

Даты эфира в Японии на главной нет намеренно: расписания выхода озвучки не существует, а японская
дата не отвечает на вопрос «что можно включить». Календарь остался отдельным экраном за кнопкой.

**Как считается «Новые серии».** Источник — [Kodik](#новые-серии-kodik). Сколько серий вы не
посмотрели, плагин знает из вашего списка Shikimori (точно) или из отметок просмотра Lampa. Тогда
на карточке зелёным `+N`. Если прогресса нет ниоткуда, а озвучка обновлялась на днях — тайтл всё
равно показывается, но без счётчика: честнее показать «18 серия · AniLiberty», чем выдумать число.

**Как считается «Я смотрю».** Сверху — закладки категории «Смотрю» как есть. Следом — вычисленное:
всё, где есть ваш прогресс и остались непросмотренные серии, из любой категории избранного и из
списка Shikimori. Тег в Lampa ставится руками и не снимается, поэтому досмотренное висит в нём
месяцами; вычисленная часть от этого свободна — тайтл уходит из неё сам.

**Убрать лишнее.** Долгое нажатие на карточке → «Не интересует»: тайтл исчезает из всех личных
строк. Вернуть — в настройках, «Скрытые тайтлы». Там же в меню — «Отметить просмотренным до серии N»
для того, что досматривали не в Lampa.

На пункте меню «Аниме» показывается число тайтлов с новыми сериями.

### Каталог и фильтры

Экран каталога открывается кнопкой «Каталог». Сверху — штатная панель `Lampa.Filter`
(«Поиск / Сортировка / Фильтр»), как в родном каталоге приложения:

- **Поиск** — текстовый поиск по названию (экранная клавиатура Lampa)
- **Жанр** — мультивыбор из жанров Shikimori (отмеченные помечены галочкой)
- **Тип** — TV, фильм, OVA, ONA, спешл, TV-спешл
- **Статус** — онгоинг, анонс, вышло
- **Сезон** — текущий и прошлые сезоны, годы, 1990-е, 1980-е
- **Оценка** — от 9 / 8 / 7 / 6
- **Сортировка** — по популярности, рейтингу, дате выхода, названию, случайно
- **Сброс** — очистить все фильтры

Выбранное значение видно прямо в панели («Статус: Онгоинг»).
Пагинация — бесконечная прокрутка по 36 карточек.

### Новые серии (Kodik)

Источник строки «Новые серии» — [Kodik](https://kodik-api.com): он ищет по `shikimori_id` и отдаёт
`last_episode` **по каждой студии озвучки**, то есть отвечает на вопрос «серию уже можно
посмотреть по-русски», а не «серия вышла в Японии».

Как это устроено:

1. Раз в 30 минут подтягиваются 2 страницы ленты `/list?sort=updated_at` — это примерно сутки релизов.
2. Тайтлы из «Я смотрю», которых в ленте не было, добираются точечно через `/search?shikimori_id=`
   (не больше 8 запросов за обновление, только онгоинги).
3. Результат пересекается с вашими списками Shikimori и закладками Lampa (через маппинг в TMDB).
4. Сколько серий вы не видели: для списков Shikimori — точное число из вашего списка; для закладок
   без Shikimori — сколько серий было при первой встрече тайтла.
5. Серия считается новой 14 дней. Дальше это уже не новинка, а недосмотренный бэклог — он виден
   в «Я смотрю».

Ограничения, о которых честно стоит знать:

- Kodik — неофициальный агрегатор. Домен уже переезжал (`kodikapi.com` отключён регистратором
  в марте 2026), поэтому адрес вынесен в настройки.
- Токены — общий публичный пул, они периодически умирают. Встроено три; если перестанут работать,
  впишите свой в настройках. Плагин сам перебирает токены при любой ошибке.
- Если Kodik недоступен, строка просто не появляется — остальной плагин работает как обычно.
- Строку можно выключить: настройки → «Строка "Новые серии"».

### Матчинг с TMDB и CUB

При клике по карточке плагин находит соответствующую запись TMDB и открывает штатную карточку Lampa
(со всеми источниками, торрентами и закладками — то есть работает и CUB-синхронизация):

1. Кэш соответствий в `Lampa.Storage` (30 дней; отрицательные результаты — 3 дня)
2. [ARM](https://arm.haglund.dev) — маппер MyAnimeList → TMDB (id Shikimori = id MAL); для списков
   и календаря запрашивается батчем
3. Если у ARM нет TMDB, но есть IMDB/TVDB — TMDB `find/{id}?external_source=…`
4. Фолбэк — поиск TMDB по названию (english → romaji → русское) с очисткой «Season N»/«Part N»,
   оценкой по схожести названия, году, жанру «Анимация» и японскому происхождению. При нескольких
   близких кандидатах показывается список выбора

### Карточка фильма

Для аниме-карточек (жанр 16 + японское происхождение) плагин добавляет:

- рейтинг Shikimori рядом со штатными рейтингами
- строку «Следующая серия: N серия · дата» для онгоингов

### Списки Shikimori

Ник в настройках достаточно указать, чтобы читать публичные списки — OAuth для этого не нужен,
но приватность профиля должна быть открытой. Данные берутся из `GET /api/v2/user_rates` +
GraphQL `animes(ids:)`, кэш 10 минут.

### Синхронизация прогресса

Просмотренное в Lampa можно записывать в ваш список на Shikimori. Нужен OAuth, а ключи приложения
в плагин не вшиты: репозиторий публичный, PKCE у Shikimori нет, и вшитый `client_secret` прочитал бы
кто угодно. Поэтому приложение регистрирует каждый сам.

1. https://shikimori.io/oauth/applications → New Application, Redirect URI `urn:ietf:wg:oauth:2.0:oob`,
   права `user_rates`
2. Client ID и Client Secret — в настройки плагина
3. «Подключить Shikimori» → на экране QR, подтверждаете вход с телефона и вводите код с сайта
4. Включить «Отправлять прогресс в Shikimori»

Прогресс только увеличивается; статусы и оценки плагин не трогает, так что испортить список он не
может. Токен живёт сутки и обновляется сам (Shikimori меняет и refresh-токен — хранятся оба).

## Настройки

Настройки → Аниме Shikimori:

| Параметр | Описание |
|---|---|
| Версия плагина | Что реально загружено. Плагин внедряется один раз при старте — если версия старая, перезапустите Lampa |
| Ник на Shikimori | Профиль, из которого читаются списки. При подключении по OAuth подставляется сам |
| Client ID / Client Secret | Ключи вашего приложения Shikimori, только для синхронизации |
| Подключить Shikimori | QR для входа с телефона и ввод кода |
| Отправлять прогресс в Shikimori | Записывать просмотренное в ваш список |
| Вид карточек | Как в Lampa (по умолчанию), Компактный, Крупные постеры |
| Показывать 18+ | Отключает фильтр цензуры Shikimori |
| Строка «Новые серии» | Главный переключатель данных Kodik |
| Засчитывать субтитры | Считать серию вышедшей, если есть только субтитры |
| Скрытые тайтлы | Убранные через «Не интересует», отсюда же возвращаются |
| Студии озвучки | Считать серию вышедшей только от выбранных студий. Не выбрано — от любых |
| Адрес Kodik API | По умолчанию `kodik-api.com`. Менять, если домен снова переедет |
| Токен Kodik | Свой токен, если встроенные перестали работать. Пусто — используются встроенные |
| CORS-прокси | Префикс перед адресом Shikimori, если прямой доступ заблокирован |
| Очистить кэш | Сброс сопоставлений TMDB, календаря, жанров, списков, известных серий и скрытых тайтлов |

## Как это устроено

Один ES5-файл без сборки, как и все плагины Lampa. Основные части:

- `NetPool` — отменяемый XHR-слой (каждый компонент чистит свои запросы в `destroy`)
- `Shiki` — API Shikimori: GraphQL для каталога, карточек и связей, REST для календаря и списков
- `Auth` — OAuth-поток для ТВ: QR, код с сайта, обновление токенов
- `Kodik` — заменяемый адаптер доступности озвучки: настраиваемый хост, перебор токенов,
  лента `/list` и точечный `/search`, хранилище известных номеров серий, фильтр по студиям
- `Progress` — прогресс просмотра из отметок Lampa (`Timeline`, `online_watched_last`)
- `Match` — сопоставление MAL → TMDB и обратное TMDB → MAL, оба с кэшем на 30 дней
- `Hidden` / `Sync` — скрытые тайтлы и отправка прогресса в Shikimori
- `UserData` — закладки Lampa, отслеживаемое, продолжения, свежая озвучка, календарь
- `ShikiCard` / `ActionCard` — карточки с бейджами по углам и полосой прогресса
- `MainComponent` (на `Lampa.InteractionMain`) и `CatalogComponent` (собственная сетка + шапка фильтров)

Ловушки Lampa, на которые здесь уже наступали: `wath` — это «Позже», а «Смотрю» — `look`;
`Line.append()` помечает отрисованный объект `ready` и во второй строке молча его пропускает;
закладка проходит через `Utils.clearCard`, и с полной карточки в ней остаётся `genres`, а не
`genre_ids`; сколько карточек рисовать в строке, решает сама Lampa — плагину этот рычаг не пробрасывается.

### Источники данных

| Данные | Endpoint |
|---|---|
| Каталог, поиск, карточки | `POST https://shikimori.io/api/graphql` |
| Списки пользователя | `GET https://shikimori.io/api/v2/user_rates?user_id=&target_type=Anime` |
| Календарь серий | `GET https://shikimori.io/api/calendar` |
| Жанры | `GET https://shikimori.io/api/genres` |
| Детали для карточки | `GET https://shikimori.io/api/animes/{mal_id}` |
| MAL → TMDB | `GET/POST https://arm.haglund.dev/api/v2/ids` |
| Популярное в Lampa | `https://tmdb.{cub_domain}/?sort=now_playing&cat=anime` |
| Доступность озвучки | `GET https://kodik-api.com/list` и `/search?shikimori_id=` |

Обращения идут на `shikimori.io` (домен `shikimori.one` редиректит без CORS-заголовков, из браузера
не работает). У Shikimori лимит 5 запросов/сек, поэтому календарь кэшируется на час, жанры — на
сутки, списки — на 10 минут.

Kodik запрашивается только простым GET без собственных заголовков: `OPTIONS`-преflight у него
отвечает 500, а ответы с ошибкой приходят без CORS-заголовков — в браузере это неотличимо от
сетевого сбоя, поэтому любая неудача трактуется как «токен мёртв» и берётся следующий.

## Ограничения

- Записи в списки Shikimori нет (нужен OAuth) — плагин работает только на чтение
- Списки профиля должны быть публичными
- «Сейчас смотрят в Lampa» использует агрегированный каталог CUB: отдельного API счётчика
  просмотров за 30 дней у Lampa/CUB не существует
- Один тайтл TMDB может соответствовать нескольким записям Shikimori (сезоны), карточка открывается
  на уровне сериала
