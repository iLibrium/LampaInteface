# Исправление ошибки в плагине

1. **Понять случай.** Какой тайтл, какая строка, что ожидалось. Для аниме найдите его сезоны:
   Shikimori id, `themoviedb-season` в ARM — по `Fribb/anime-lists`
   (`curl -s https://raw.githubusercontent.com/Fribb/anime-lists/master/anime-list-full.json`),
   сезоны TMDB — что видит пользователь в карточке Lampa.

2. **Воспроизвести сценарием.** В `tests/run.js` — сценарий с миром той же структуры
   (см. `tests/README.md`). Он должен падать на `main`:
   ```bash
   cd tests && npm install
   git show origin/main:shikimori.js > .cache/main.js
   node run.js .cache/main.js имя_сценария
   ```
   Если ошибка в отрисовке, фокусе или полной карточке — проверьте в настоящей Lampa
   (`npm run setup`, затем `e2e*.js`; образец — `e2e_k.js`, `e2e_mark.js`).
   Если ошибка оказалась в самой Lampa, а не в плагине, покажите это тем же тестом с плагином и без.

3. **Исправить** в `shikimori.js` — только ES5, комментарий по-русски о том, что ломалось.

4. **Проверить:** `npm run check` (ES5, eslint, все сценарии) и `npm run e2e`.
   Сценарий из шага 2 проходит, остальные не сломались.

5. **Ревью агентами** из `.claude/agents`: `season-logic-reviewer` (прогресс, сезоны),
   `lampa-runtime-reviewer` (кеши, сеть, ES5, фокус), `adversarial-tester` (новые сценарии).
   Каждую их находку подтвердите сценарием, прежде чем исправлять.

6. **Выпуск:** поднять `VERSION`, описать изменение в `README.md`, PR в `main`.
