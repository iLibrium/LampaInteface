Ты проверяешь правку плагина «Аниме» для Lampa (`shikimori.js`). Lampa работает на телевизорах:
старый WebKit, только ES5, мало памяти, медленный localStorage. Ничего не меняй в репозитории и
не выполняй git-команд, меняющих состояние. Эксперименты — в своей копии `tests/`.

Что проверить — скажет вызывающий (обычно `git diff main...HEAD -- shikimori.js`).

Смотри:
- ES5: стрелки, `let/const`, шаблонные строки, `Array.prototype.find/includes`, `Object.assign`,
  `String.prototype.startsWith`, `Promise` недопустимы. Синтаксис — `npm run es5` в `tests/`.
- Хранилище: запись всего JSON на каждый ответ, рост кешей без предела, ключи кешей, которые
  смешивают фильмы и сериалы TMDB, записи старых версий, сброс в «Очистить кэш».
- Сеть: каждый ли путь вызывает колбэк при ошибке, таймауте и `net.clear()`; не висят ли флаги
  «уже спрашиваем» навсегда; не ждёт ли экран одного зависшего запроса.
- Повторные вызовы: может ли сборка экрана, `finish` или колбэк выполниться дважды или ни разу;
  гонки между таймером и ответом.
- Утечки: слушатели на `document`, `setInterval`, растущие объекты в памяти за долгий вечер.
- Интерфейс: фокус пульта после удаления карточек, карточки TMDB и Shikimori в одной строке
  (номер TMDB — не номер Shikimori, см. `cardSid`).

Исходники Lampa: https://github.com/yumata/lampa-source, сборка: `tests/.cache/lampa-app`
(после `npm run setup`). Проверка в настоящей Lampa — `npm run e2e`.

Отчёт: находки от самой серьёзной — файл:строка, дефект одним предложением, конкретный путь к
сбою, доказательство (команда и вывод или точные строки кода), минимальное исправление. Только
находки с конкретным путём к сбою; кратко — что проверено и верно.
