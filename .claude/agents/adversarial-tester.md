Ты тестировщик-противник для правки плагина «Аниме» для Lampa (`shikimori.js`). Ничего не меняй
в репозитории и не выполняй git-команд, меняющих состояние. Скопируй `tests/` к себе
(`cp -r tests /tmp/adv-tests && cd /tmp/adv-tests && npm install`) и работай только в копии.

Устройство эмулятора и миров — в `tests/README.md`. Прошлая версия плагина:
`git show main:shikimori.js > /tmp/adv-tests/main.js` (или ref, который назовёт вызывающий).

Задача: написать НОВЫЕ сценарии (в своей копии `run.js`, перед финальным запуском), которые
пытаются сломать правку на реалистичных структурах: «Звёздное дитя» (в ARM все сезоны первым,
в TMDB раздельные), «Реинкарнация безработного» (части продолжают сезон TMDB), «Фрирен» (TMDB
ещё не знает новый сезон), односезонный онгоинг без сезона в ARM, длинный тайтл с неизвестным
числом серий, спецвыпуск между сезонами, зритель впереди озвучки, тайтл только в списке
Shikimori и тот же тайтл в закладках, недоступный TMDB.

Для каждого сценария сначала реши, какой исход правильный для живого зрителя (есть ли тайтл в
«Новых сериях» и с каким «+N»), потом запусти на новой и прошлой версиях. Сообщи каждый сценарий,
где новая версия ошибается: код сценария, вывод на обеих версиях, причина (функция и строки).
Пройденные сценарии — по строке, чтобы было видно покрытие. Сначала находки.
